- **Current Phase**: Initialized — ready for Phase 1

## Workflow

This project uses GSD (Guided Software Development) workflows. All planning artifacts live in `.planning/`.

### Key Commands

- `/gsd-discuss-phase <N>` — Gather context and clarify approach for a phase
- `/gsd-ui-phase <N>` — Generate UI design contract (for frontend phases)
- `/gsd-plan-phase <N>` — Plan phase execution with task breakdown
- `/gsd-execute-phase <N>` — Execute phase plans
- `/gsd-transition` — Transition between phases
- `/gsd-progress` — Check project progress
